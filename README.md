# 📝 NLP Text Analyzer App

This project is an interactive Natural Language Processing (NLP) application built using Python and Streamlit. The app allows users to perform core text analysis tasks including tokenization, stemming, lemmatization, sentiment analysis, and word cloud generation on custom input text.

The app is designed for both learning NLP concepts and exploring text data in an easy-to-use, interactive environment.

## 📊 Data Processing & Analysis

Text Cleaning: Converts text to lowercase and removes punctuation.

Stopwords Removal: Filters out common words to focus on meaningful terms.

Tokenization: Splits text into words or sentences for analysis.

Stemming: Reduces words to their root forms using Porter Stemmer.

Lemmatization: Normalizes words to their base form using WordNet Lemmatizer.

## 📈 Sentiment Analysis

Uses Vader Sentiment Analyzer to classify input text as positive, negative, or neutral.

Provides real-time sentiment scoring for quick insights.

## 🌐 Visualization

Word Cloud: Generates a visual representation of word frequency from the processed text.

Utilizes Matplotlib for clear and interactive visualizations.

## 🛠️ Technologies Used

Python – core programming and NLP logic

Streamlit – interactive web interface

NLTK – tokenization, stemming, lemmatization, stopwords

VaderSentiment – sentiment analysis

WordCloud & Matplotlib – visualization

## 🚀 Features

Interactive sidebar to select tokenization type (word or sentence).

Toggle options for stemming, lemmatization, and word cloud generation.

Real-time sentiment analysis results.

Clean, modular, and beginner-friendly interface.
